# Спецификации для таблицы метаданных StreamShelf

Дата поиска: 3 ноября 2026. Это реестр источников, а не готовая таблица применимости и не результат проверки FFmpeg.

## Контейнеры

| Формат | Документ | Что проверять |
|---|---|---|
| Matroska/MKV | [RFC 9559](https://www.rfc-editor.org/rfc/rfc9559.html) | TrackEntry, Name, Language, LanguageBCP47, флаги, Tags и TagTrackUID. |
| Matroska/MKV | [Matroska Tags](https://www.matroska.org/technical/tagging.html) | Словарь имен тегов, включая TITLE, ARTIST, DATE_RELEASED и уровни применения. |
| WebM | [WebM Container Guidelines](https://www.webmproject.org/docs/container/) | Какие элементы Matroska разрешены в WebM, включая язык и цели тегов. |
| MP4 | [ISO/IEC 14496-12:2026](https://www.iso.org/standard/85596.html?browse=tc) | Структуры дорожек, языки и контейнерные метаданные; доступность полного текста нужно проверить отдельно. |
| QuickTime/MOV | [QuickTime metadata atoms](https://developer.apple.com/documentation/quicktime-file-format/metadata_atoms_and_types) | Метаданные уровня movie, track и media; atoms meta, hdlr, keys, ilst. |
| QuickTime/MOV | [User data atom](https://developer.apple.com/documentation/quicktime-file-format/user_data_atom) | Пользовательские данные и track name atom tnam. |

## Кодеки и аудиоформаты

| Кодек/формат | Документ | Что проверять |
|---|---|---|
| H.264/AVC | [ITU-T H.264](https://www.itu.int/myworkspace/t-rec/item?number=H.264) | Технические параметры битового потока, VUI и SEI; редакция документа имеет значение. |
| AV1 | [AV1 Bitstream & Decoding Process](https://aomediacodec.github.io/av1-spec/) | color_config, OBU_METADATA и HDR-параметры. |
| AV1 в MP4 | [AV1 ISO BMFF binding](https://aomediacodec.github.io/av1-isobmff/v1.2.0.html) | Связь параметров AV1 с контейнером и запись конфигурации. |
| Opus в Ogg | [RFC 7845 §5.2](https://www.rfc-editor.org/rfc/rfc7845.html#section-5.2) | OpusTags, TITLE, ARTIST, DATE, R128_TRACK_GAIN и R128_ALBUM_GAIN. |
| Vorbis | [Xiph Vorbis comments](https://www.xiph.org/vorbis/doc/v-comment.html) | Имена текстовых комментариев и их семантика. |
| FLAC | [RFC 9639 §8](https://www.rfc-editor.org/rfc/rfc9639.html#section-8) | STREAMINFO, VORBIS_COMMENT, PICTURE и другие блоки. |
| MP3/ID3 | [ID3v2.4 frames](https://id3.org/id3v2.4.0-frames) | Идентификаторы и значения кадров ID3. |

## Реализация и проверка

- [FFmpeg: -metadata и -map_metadata](https://ffmpeg.org/ffmpeg.html): отображение метаданных в параметрах командной строки, не гарантия для каждого контейнера.
- [MediaInfo Fields](https://mediaarea.net/en/MediaInfo/Support/Fields): нормализованные имена полей чтения и их сопоставления с другими схемами.
- [MediaInfoLib, парсер Matroska](https://github.com/MediaArea/MediaInfoLib/blob/master/Source/MediaInfo/Multiple/File_Mk.cpp): примеры чтения тегов дорожки по TagTrackUID.

Для каждого поля итоговая таблица должна отдельно фиксировать: разрешено спецификацией, проверено при записи выбранной версией FFmpeg, прочитано ffprobe/MediaInfo и отображается проигрывателем. Отсутствие проверки нельзя считать запретом формата.
