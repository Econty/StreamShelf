# Миниатюры, окно и VS Code — 28 октября 2026

Работа выполнена локально на ноутбуке пользователя. Исходники открыты в VS Code в этой папке.

## Изменения

- По умолчанию обзор использует карточки с настоящими изображениями. Техническая таблица доступна отдельной кнопкой.
- Миниатюры сохраняют пропорции. PNG/JPEG декодируются Windows Imaging Component; видео без обложки получает первый доступный кадр через локальный FFmpeg. Для HLS/DASH также выполняется попытка получить кадр с ограничением времени. Если источник недоступен или защищён, показывается отсутствие превью.
- Обложка связывается с конкретным видео по video.poster или соответствующему объекту JSON. Для yt-dlp используется thumbnail из результата анализа. Чужая случайная картинка не подставляется.
- Превью загружаются двумя фоновыми задачами; временные кадры удаляются. Cookies/Authorization не записываются в обычные журналы. Cookie store FFmpeg содержит домен и путь, глобальный Authorization ему не передаётся. DRM обход не добавлялся.
- Удалены рекламные заголовки, дублирующие подписи и технический декор боковой панели. При узком окне боковая панель сокращается до значков, карточки переносятся по ширине.
- Полосы прокрутки получили видимый трек и более широкий ползунок. У таблицы отделено место под горизонтальную полосу.
- Разворачивание/восстановление меняет геометрию с плавным замедлением за 230 мс. Сворачивание использует анимацию Windows, а не macOS Genie. Настройка «Уменьшить движение» отключает собственный переход.
- Добавлена встроенная иконка. Ярлыки StreamShelf.lnk созданы на рабочем столе и в меню «Пуск» текущего пользователя.

## Проверка превью

- 6 нативных проверок WIC: PNG, JPEG, ограничение размера, пропорции, порядок RGBA-каналов, повреждённый и чрезмерный вход.
- 32 проверки обнаружения для Chromium/Firefox через mock DOM/WebExtension, включая связь постера и заголовка с конкретным видео. Это не реальный запуск Firefox.
- В настоящем окне StreamShelf отображены две собственные тестовые картинки PNG/JPEG и цветной кадр собственного тестового MP4. Тестовые файлы обслуживались только локальным HTTP-сервером 127.0.0.1; он остановлен после проверки.
- Реальный Native Messaging host получил запросы credentials для каждого из трёх точных тестовых адресов и ответил пустой тестовой сессией. Пользовательские cookies для этих тестов не использовались.
- Ранее пройденные 24 проверки ядра, 6 проверок duplex-связи и 19 прежних JS-проверок прошли при сборке этого изменения.
- Полная проверка превью всех личных вложений Авито и всех сетевых кодеков не выполнялась.
- При фактическом подключении Яндекс Браузера к Авито Сообщениям в карточках увидены реальные изображения и кадры двух HLS-ресурсов. У части потоков превью недоступно; это явно показано. Личные URL, снимки переписки и изображения в отчёт не сохранялись.

## VS Code

Установлены Microsoft C/C++ и русский языковой пакет. compilerPath указывает на проверенный локальный LLVM-MinGW. Ctrl+Shift+B запускает scripts/Build-Local.ps1 (полная сборка приложения, ресурса иконки и проверки). F5 настроен через cppdbg и имеющийся lldb-mi.exe. Configure-on-open CMake отключён, чтобы не перекрывать редактор запросом выбора другого компилятора.

Фактическая проверочная компиляция выполнялась тем же компилятором через локальный терминал инструмента. Нажатие Ctrl+Shift+B и отладочная сессия F5 в интерфейсе редактора этим прогоном не проверялись. Настройка сохранена в .vscode/tasks.json, .vscode/c_cpp_properties.json и .vscode/launch.json.

Скрипт scripts/Create-Shortcut.ps1 повторно создаёт ярлыки. Готовый EXE установлен в C:\Users\Арсений\Downloads\StreamShelf-Native; native host обновлён в пользовательском каталоге приложения. Резервные копии заменённых файлов находятся в backups/.
