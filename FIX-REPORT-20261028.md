# Устранение зависания поиска: локальная Windows-сборка

Проверено 28 октября 2026 на этом ноутбуке, Windows 11 x64. Этот отчёт дополняет исходный VERIFICATION.md из архива, в котором описана прежняя Linux-кросс-сборка.

## Причина и исправление

Синхронный ReadFile ожидал данные в duplex named pipe. Запись в тот же синхронный handle блокировалась за чтением; кнопка поиска выполняла запись непосредственно в потоке интерфейса. После завершения старого native host зависшее приложение сразу снова отвечало.

Обе стороны pipe переведены на overlapped I/O с отдельным событием для каждой операции. Запись имеет ограниченное время ожидания. При отмене незавершённая операция завершается до освобождения её буфера. Отправка команды из интерфейса выполняется в рабочем потоке; повторные нажатия до её завершения блокируются.

Протокол 1, native-host name, ID расширения и существующая регистрация сохранены. Пользовательские cookies, настройки и очередь не изменялись.

## Дополнение: независимый анализатор и адаптация окна

Собрана и установлена следующая локальная Windows x64 версия. SHA-256 StreamShelf.exe и StreamShelf.Host.exe: B25C792BE28E10D716D18F4F9B3D1E6B903C0709E41FBDECB6A0AA3EBEECB3CD.

Независимый от yt-dlp анализатор теперь проверяет элементы video/audio/source/track/img, превью, известные атрибуты отложенной загрузки, встроенный JSON и JSON-LD с медиаобъектами, буквальные медиаадреса в коде, Resource Timing уже загруженных ресурсов и новые сетевые ответы. Код страницы не исполняется анализатором. Неизвестный fetch/XHR не объявляется медиапотоком только по факту запроса. Адреса blob: не выдаются за скачиваемые HTTP-файлы. Поиск наблюдает только выбранную вкладку. Исправлены потеря элементов после первых 200 результатов и остановка повторно внедрённого наблюдателя. Видео/аудио не вытесняются большим количеством картинок из ограниченного списка.

Для неподдерживаемой страницы yt-dlp приложение объясняет переход к независимому поиску. В реальном окне StreamShelf подтверждены подключение Яндекс Браузера к Авито Сообщениям и появление 60 ресурсов, включая строки «Видео» с источником DOM (позднее счётчик вырос до 61). Полнота списка, содержимое личных вложений и воспроизведение/скачивание каждого ресурса не проверялись; личные URL и содержимое переписки в этот отчёт не копировались. Новые файлы расширения сохранены и в portable-папке, и в пользовательском каталоге connector. Загруженный до обновления background service worker может потребовать обычной перезагрузки существующего расширения для применения всех его изменений; новый content script уже использован при повторном запуске поиска.

Начальный размер окна ограничен рабочей областью монитора; на небольших рабочих областях окно стартует развёрнутым. Разворачивание использует rcWork, сохраняя место панели задач. Значок разворачивания/восстановления рисуется линиями, а не отсутствующим в атласе символом. Захват мыши освобождается до смены состояния окна. Минимальные размеры снижены, интерфейс подстраивается под доступную площадь, а нативный курсор изменения размера не перезаписывается отрисовкой. В компактном режиме шапка обзора занимает меньше места; очередь получает более высокую область списка и компактные строки, нижние кнопки распределяются по ширине.
