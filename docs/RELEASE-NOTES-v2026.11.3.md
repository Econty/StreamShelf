# StreamShelf v2026.11.3 Beta

- Карточка пробует загрузить обложку и, если её нет, извлечь кадр из видео или прочитать вложенную обложку аудио. Завершённые загрузки используют локальный файл. Если обложки или доступного кадра нет, карточка показывает подпись.
- Для прямого защищённого медиа кадр извлекается из ограниченного фрагмента, полученного самой программой. Cookies и заголовок авторизации не передаются FFmpeg через командную строку. Для защищённых HLS/DASH по-прежнему нужна отдельная обложка.
- Connector 1.0.6 различает смену вкладки и обновление доступа. Повторный фокус той же вкладки или обновление срока действия неизменившейся cookie не сбрасывают поиск. При смене авторизации сохранённые данные доступа не смешиваются с новыми.
- Данные доступа браузера хранятся в ограниченном зашифрованном кэше в памяти и привязаны к соединению, вкладке, контейнеру браузера и точному адресу. Уже начатая передача может завершиться с полученными данными.
- Установщик не входит в эту сборку. Уже установленный подписанный Firefox Connector 1.0.5 может подключаться, но исправления на стороне расширения требуют подписанного Mozilla Connector 1.0.6.
