# StreamShelf v2026.11.2 Beta

- Восстановлено автоматическое открытие папки подписанного XPI в подтверждённом диалоге Firefox. Сохраняется вручную выбранный файл.
- Ввод внутреннего адреса проверяет принадлежность поля панели браузера, а не только подпись «Поиск».
- Повторная настройка подключения доступна после разрыва связи.
- Клавиатурная рамка Tab рисуется сглаженным скруглённым контуром, плавно появляется и затухает. Через три секунды без нового Tab визуальная рамка скрывается, фактический фокус сохраняется.
- Выбор медиа и загрузок выполняется всей карточкой или строкой. Отдельные галочки и их Tab-остановки убраны; выбранные элементы сохраняют толстую скруглённую рамку.
- Сохранены множественный выбор, выбор всех, Enter/Space и доступные состояния элементов списка.

## Короткая проверка сборки

Прошли семь CTest-наборов: focus_visual, guide_flow_resume, extension_installer, native_core, js_font-coverage, connector_install_locked_host, guide_profile_challenge.

В GUI новой программы на локальном тестовом MP4 проверены выбор карточкой, снятие выбора Space, выбор Enter, множественный выбор строк, затухание Tab с сохранением фокуса и повторное появление по Shift+Tab. OpenGL-шейдер сглаживания успешно загружен настоящим интерфейсом.

В настоящем Chrome подтверждены запуск мастера, связь с установленным расширением и автоматическое закрытие. Firefox и Яндекс Браузер в этом коротком GUI-проходе не проверялись. Ранее установленное ограничение инструмента для Firefox сохраняется.

Установщик не пересобирался. Подписанный Firefox Connector 1.0.5 не изменялся. Для работы exe нужны соседние папки Assets и extensions, включая новый Assets/shaders/desktop.frag.
