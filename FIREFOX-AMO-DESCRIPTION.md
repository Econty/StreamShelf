# StreamShelf Connector — описание для Mozilla Add-ons

StreamShelf Connector связывает Firefox с программой StreamShelf для Windows и помогает находить медиа на открытой странице.

Расширение передаёт адрес и название активной вкладки локальной программе. После запуска глубокого анализа в StreamShelf оно помогает обнаруживать медиаэлементы, ресурсы страницы и доступные HLS/DASH-потоки. Для динамических ресурсов может потребоваться запустить воспроизведение или обновить страницу.

Для работы нужна установленная программа StreamShelf. При подключении пользователь подтверждает запрашиваемый браузером доступ к сайтам. По запросу приложения расширение передаёт ему необходимые cookies и HTTP-заголовки через локальное соединение Native Messaging. Расширение не отправляет эти данные на сервер разработчика. Страница и ресурсы могут быть переданы программе для обращения к исходному сайту при анализе и загрузке.

Доступность медиа зависит от сайта и разрешений пользователя. Расширение не обходит DRM.

## Примечание для рецензента

Исходный код JavaScript и HTML включён в пакет без сборки и минификации. Native Messaging host `dev.streamshelf.connector` устанавливается приложением StreamShelf для Windows. Расширение использует фиксированный ID `connector@streamshelf.local`. Для работы функций требуется Firefox 140 или новее и разрешение пользователя на доступ к сайтам.
